## Week 2 – Day 6: TypeScript Basics & Profile Validator

- **`src/ts-basics/`**: Core TypeScript syntax exercises covering tuples, functions, objects, type aliases, union types, and optional chaining.
- **`src/profile-validator.ts`**: Defines a `UserProfile` type alias with optional nested properties (`settings?.notifications`) and implements `isNotified(user)` using optional chaining (`?.`) and nullish coalescing (`??`) to safely handle incomplete API payloads.
